# One Letter: Coffee or Tea

One letter: **A for coffee**.

Coffee is the bolder, more vivid, funnier choice — bold flavour, the morning jolt, builder-fuel humour — versus tea's calm gentleness, so A is the stronger stance on vividness and humour.

## Run

```bash
python3 main.py
```

Writes exactly one byte, `A` with no trailing newline, to `/output/entry.txt` (or `$ENTRY_OUTPUT` if set).
